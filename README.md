### About me

I work on both sides of the application: I build back-end and full-stack systems in **Java / Spring Boot** and **React / Node.js**, and I test web apps, APIs and networks as an **OSCP-certified penetration tester**.

- 🔐 Focus areas: web & API security, OAuth / auth flaws, GraphQL, web cache deception, Active Directory
- 🛠️ I build small tools and labs to automate recon and reproduce real-world bugs
- 🐞 Active in bug bounty and responsible disclosure
- 💬 Open to AppSec, pentesting and secure-development roles and collaborations
